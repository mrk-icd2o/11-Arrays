# Lab 11 - Grocery List

You will be writing your code in `sketch.js` within the main folder - not the `example/` folder.

Re-create [this program](https://openprocessing.org/sketch/981880/embed/?plusEmbedHash=d07f5eb0&userID=175929&plusEmbedTitle=true&show=sketch). The input box and buttons are already set up for you in `sketch.js`.

- The **Add** button adds the typed item to the grocery list, **only if it doesn't already exist**.

- The **Delete** button removes the typed item from the grocery list, **only if it exists**.

- The list can hold a **maximum of 10 items**.

- If **apples** or **chicken** is added, it is coloured green.

Remember to:

- Update the header

- Include comments
